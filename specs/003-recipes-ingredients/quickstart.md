# Quickstart: Recipes and Ingredients Web

```bash
pnpm api:check
pnpm lint
pnpm typecheck
pnpm test
pnpm test:e2e
pnpm test:a11y
pnpm build
pnpm audit --audit-level=high
pnpm licenses:check
pnpm performance:check
```

Use synthetic household data and the API 003 snapshot. Verify browse/search/detail/draft/publish/favorite flows and explicit loading/empty/error/forbidden/conflict states. No email or deployment is required.
